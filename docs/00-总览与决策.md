## 2. 产品范围

| 产品 | 架构 | 数据与能力 |
| --- | --- | --- |
| Web | Svelte 5 + Vite；保留Hono Worker | Cloudflare D1、R2或KV、Durable Objects；原应用完整功能、移动布局、PWA、分享、备份、MCP、可选语义搜索 |
| Desktop | Tauri 2 + SvelteKit static + Rust | 本地SQLite与附件，离线可用，可选连接Web实例同步；提供本地MCP服务端 |
| shared | packages/shared | 纯TS领域类型、语言包、Markdown纯函数与备份合同 |
| app | packages/app（计划新增） | 两端共享Svelte界面、状态、编辑器、渲染，仅经Backend访问宿主 |

桌面云端公开分享、WebDAV/S3定时备份、语义搜索、独立CLI目前不纳入详细实现范围；这是前次选项未勾选后的规划基线，不宣称用户永久否决这些功能。Web保留它们。桌面一个库绑定一个远端账号；切换绑定不得混用旧账号队列。

## 3. 已确定约束

| 编号 | 决策 | 依据 |
| --- | --- | --- |
| D1 | 一个monorepo，Web与桌面独立构建/发布 | 用户同意统一仓库 |
| D2 | Web移植Hono Worker，保持API、存储与备份格式兼容 | 用户选择移植 |
| D3 | 桌面本地SQLite为主，可选同步Cloudflare实例 | 用户选择 |
| D4 | 桌面提供MCP服务端，不是外部MCP客户端 | 用户追加 |
| D5 | 两端不用React；Svelte 5 runes | 用户要求 |
| D6 | Web纯Svelte/Vite保留Worker入口；桌面SvelteKit静态适配 | 保守迁移方案，非要求两宿主框架层完全相同 |
| D7 | 产品名AutoNote，图标来自docs/autonote.png | 用户确认；另一张ChatGPT图片不提交 |
| D8 | 桌面所有运行期数据在exe同级data，不使用系统AppData | 用户要求；安装目录须可写，不能隐式换目录 |
| D9 | 本地使用绿色MSVC，默认D:/Applications/msvc-portable/msvc | 用户要求；不因为PATH已有Build Tools就跳过 |
| D10 | Web推送只做检查，部署由main手动勾选deploy | 用户要求；项目完成后另行改自动部署，不提前切换 |
| D11 | 所有阶段先写概要/详细设计，再拆模块任务，最后开发 | 用户要求；任务粒度一个模块或一组文件 |

已采用的工程选择：pnpm工作区；桌面MCP优先维护中的Rust SDK + 回环Streamable HTTP；同步复用现有会话API而不是把MCP API Key当REST令牌。均需在对应任务真实联调验收，不把设计写成验证事实。

## 4. 发布、工具与许可证

- Web workflow：push/PR检查，只有workflow_dispatch + deploy=true + main才部署。配置Cloudflare Secrets前不能声称可部署；远端Actions通过与否以远端日志为证。
- Desktop workflow：Windows runner启用预装MSVC；本地始终绿色工具链。当前脚本以CI变量区分环境，但一般CI变量不等于GitHub身份证明；D6会把环境选择明确化，不因本机偶然CI=true选择系统工具链。
- 桌面release tag为desktop-v版本；打包版本必须与Cargo/tauri.conf/package.json一致。ZIP仅装程序/必要许可文件，不携带用户data、密钥或日志。
- 保留原参考项目 LGPL-3.0-only许可和来源声明；第三方资产/库按各自许可分发。许可证结论不是“所有新文件只能用同一许可”的法律意见，发布时核查衍生代码、链接与再分发义务。
- 仓库已存在初始提交；本轮设计不自动提交或推送，先完成一致性检查。

## 5. 风险及明确处理

1. **保存与同步不是一回事**：Web正文先本地持久、后网络防抖；桌面SQLite提交才算已保存，remote pending单独显示。
2. **三种序列不能混用**：本地rev、本地cursor、远端rev/cursor分离。远端ACK不能覆盖在途请求期间的新输入。
3. **文件与数据库不同事务**：stage/原子重命名/DB提交/引用保护/启动恢复；清理构建产物时不得删exe旁data。
4. **TS与Rust语义差异**：UTF8字节限制、UTF16计数、Unicode截断、中文分词、标签与WikiLink都要同夹具加真实行为验证。
5. **MCP可写有风险**：默认最小权限、单独trash授权、期望修订、幂等事务、回环Host/Origin校验、token撤销；不执行笔记里的指令或脚本。
6. **文档不能替代验收**：条目没有命令输出/真实窗口/跨端场景证据，不得勾完成；检查通过不等于产品完整。
