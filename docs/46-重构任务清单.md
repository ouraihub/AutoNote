### 5.5 真实目标容量阻断

对本地实现提交，在干净 detached worktree 执行同一固定版本 `release-kit review-size --base origin/main`；不移动或纳入用户未跟踪的 `docs/重构建议.md`。真实目标 `ab2b6ea61320276578e6b08663a2e1a0afdacae0`，完整差异 838 文件、6,119,508 字符、57 批；一致性请求 6,347,846 + 50,000 reserve 超过 2,000,000，累计 15,213,288 + 2,900,000 reserve 超过 6,000,000。结果 `SPLIT PR before pushing`，未调用模型或网络。

当前规则同时要求全仓尺寸门禁：把迁移拆为普通顺序 PR 时，第一批仍会扫描尚未迁移的旧文件而失败；多条 commit 不缩小同一 PR 的补丁。因而不能宣称已找到每批独立全绿的拆分方案。继续远端交付需要先明确另行审阅的迁移/评审策略；本轮没有扩大上下文、跳过补丁、豁免旧源码、关闭检查或管理员合并。本地完整实现和验收证据保留，容量门禁与浏览器环境阻断单独记录，不冒充完成合并。
