## 1. 目标、依据与非目标

目标：采用Voynote的一体输入卡片、用户／AI回复层级和消息内操作栏，保留AutoNote主题、Aether安全边界和两端真实执行链。不是复制整页、替换聊天框架或仅增加无后端行为的图标。

非目标：换Markdown解析器、引入富文本输入编辑器、引入动画库、重做模型设置、改变原生搜索路由、复制Voynote全局搜索／知识库／工作区逻辑。Voynote package.json声明UNLICENSED；参考交互，独立实现，不直接搬源码或资产。

## 2. 功能归属与接缝

| 功能 | 所有者 | 约束 |

## 7. 完整回复操作冻结合同（用户已批准）

### 7.1 参考源码事实与不允许替代

- Voynote输入框`+page.svelte:979–987`展开按钮绝对定位右上；底部有新建、联网、附件／搜索、思考和发送。AutoNote已有能力放相同区域，未授权附件不画空按钮。
- `ReplyActionBar.svelte:41–54`操作栏为左侧图标组＋右侧“用作上下文”，窄栏可按组换行；更多菜单编辑／分支／复制新对话／保存／导出，模型选择为真实重答。
- `conversation.rs:start_reply_retry`在同会话创建相同问题的候选，保留原回复；`commands/chat.rs:history()`沿所选回复祖先链构造请求，不能把所有候选塞入模型上下文。
- 禁止用“复制独立新会话”代替“用作上下文”。Voynote的分支动作（+page.svelte:567–570）选择回复并清空草稿，仍在同会话；只有“复制为新对话”（:572–579）复制路径为新会话。选择候选不得改变conversationId。
- Cherry上游只读对照：`src/renderer/components/composer/ComposerSurfaceRuntime.tsx:2308–2323`明确右上角展开，`ComposerSurface.tsx:253–358`一体容器与底部左右工具组；`chat/messages/frame/MessageMenuBar.tsx:168–187`按能力解析操作栏，`messageMenuBarActions.tsx:219–260,340–465`是真实重答／删除／分支／保存／上下文回调，按运行状态与能力门控。当前Cherry“useful”只在分组回复且支持setActiveBranch时显示；不能把图标误作点赞统计。视觉以用户Voynote截图为直接目标，Cherry用来核实语义，不复制React注册体系或花式角按钮动画。

### 7.2 最小消息结构与升级

复用既有Turn（用户问题＋完整助手／工具消息），新增parentId（上轮选中回复）、questionId（同轮候选分组）、supersedesId（重答来源）、kind（reply/translation）、endpointId（来源模型线路）；ConversationSummary新增selectedTurnId。同轮重答questionId/parentId与原轮一致，不覆盖原回复；界面同questionId只显示一次用户问题。

SQLite chat.db新增migration3，D1按既有增量初始化流程新增列；旧线性轮次按seq回填parentId，questionId=id，选中最后有效完成轮。保留正文、原生思考块、模型、密钥和真实用量；升级自动备份，不能修改已发布migration或清库。

历史选路仅沿parentId，验证所选消息属于同会话、存在、可用、无循环；外部调用不能通过foreign turnId读别的会话。普通新问题连到持久selectedTurnId；候选重答不自动切换已选路径，用户显式选择后才使用新候选。

### 7.3 请求与端口

RunRequest新增可选replyToId、retryTurnId、translateTurnId、targetLanguage；RunAccepted新增turnId用于流式阶段稳定定位。保留regenerate为重答选中轮快捷调用，但现在创建候选而不清空原回复；retry和translation互斥，显式action不与regenerate组合。ID最多128字符，翻译语言trim后1–80字符；写作拒绝上述聊天字段。

ChatHistoryPort新增必需方法：editTurn(conversationId,turnId,text,expectedText)、removeTurn(conversationId,turnId)、fork(conversationId,turnId)、selectTurn(conversationId,turnId)，均返回持久化后的Conversation。所有Rust store实现、Tauri端口、Web HTTP、fake及测试迁移，不用默认unsupported/noop掩盖。

| 行为 | Tauri command | HTTP路径（/api/ai/kit下） |
| --- | --- | --- |
| 编辑 | chat_edit_turn | PATCH /conversations/:id/turns/:turnId，{text,expectedText} |
| 删除 | chat_remove_turn | DELETE /conversations/:id/turns/:turnId |
| 复制新对话 | chat_fork | POST /conversations/:id/fork，{turnId} |
| 用作上下文／分支（分支额外清空草稿） | chat_select_turn | PUT /conversations/:id/selection，{turnId} |

重答保留source input、parent history与来源endpointId/modelId；显式切换模型时才覆盖模型。原模型已删除则明确needs_config，不静默换到默认。翻译是同会话子轮：parentId=来源回复，固定翻译指令＋原文，经真实模型运行，不前端伪造译文。执行仍包含宿主system、确认技能与用户本轮context规则。

结束事件须在结果持久化之后发送；否则按钮操作／重启读回可能抢在写库前。失败持久化不得宣称成功。

### 7.4 编辑／删除／分支不变量

- 编辑非空且最多24000字符，expectedText精确CAS；运行中、有parent/supersedes后代时拒绝。只改助手正文，清除与人工正文不一致的工具／原生思考消息，保留那次实际生成用量，contextUsage失效。失败保持编辑草稿和原回复。
- 删除仅删除目标候选，不清空整会话；运行中、已有后代、当前选中回复拒绝删除，需先选择其他候选。只有一个候选时需明确该问题／回复会被移除，不暗示用户问题仍在。
- 分支选择来源路径并清空草稿，conversationId不变；复制新对话才复制选中祖先路径、新conversationId和新Turn IDs、重映射parent/question关联，scope相同。源会话和原回复不改；原生消息保留，不执行历史工具。
- 所有变更原子，Web每次检查user_id、会话归属和目标关系；桌面按当前本地库隔离。mutation运行中拒绝，不靠按钮disabled代替后端检查。

### 7.5 回复UI与宿主

每候选有来源模型、正文、思考／来源／工具状态；操作栏复制、更多、重答、换模型、翻译、删除、保存笔记和右对齐用作上下文。没有历史端口或稳定消息ID时不提供无法执行的操作。更多菜单包括编辑、分支、复制新对话、真实Markdown文件导出。Dialog可键盘操作，Esc只关当前弹层，错误不丢草稿。

保存笔记通过Aether可选onSaveNote(markdown, images)回调；AutoNote用NotesState.create真实创建笔记，保留完整Markdown，按第一非空行提取短标题，不修改当前笔记。框架不导入笔记数据库。已有onInsert继续插入当前光标／追加。
