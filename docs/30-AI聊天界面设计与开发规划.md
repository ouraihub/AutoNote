## 1. 目标、依据与非目标

目标：采用Voynote的一体输入卡片、用户／AI回复层级和消息内操作栏，保留AutoNote主题、Aether安全边界和两端真实执行链。不是复制整页、替换聊天框架或仅增加无后端行为的图标。

非目标：换Markdown解析器、引入富文本输入编辑器、引入动画库、重做模型设置、改变原生搜索路由、复制Voynote全局搜索／知识库／工作区逻辑。Voynote package.json声明UNLICENSED；参考交互，独立实现，不直接搬源码或资产。

## 2. 功能归属与接缝

| 功能 | 所有者 | 约束 |
| --- | --- | --- |
| 输入卡片、键盘、展开、流式状态、发送／停止 | Aether UI | 复用ChatPanel／RunSession；不新建运行框架 |
| 用户气泡、AI卡片、Markdown、思考、工具审批、来源、滚动 | Aether UI | 消费通用端口和语义令牌，无AutoNote导入 |
| 模型、思考强度、联网、用量、历史与会话操作 | Aether UI | 使用既有ProvidersPort／ChatPort／SearchPort／ChatHistoryPort |
| 上下文标签显示与本轮移除 | Aether UI | 只认识kind/id/label；不读取笔记内容 |
| 当前笔记／选区、权限、正文预算、scope、角色回落与上次会话 | AutoNote | 两端经宿主解析 |
| 插入光标／追加正文、保存为新笔记、打开笔记搜索 | AutoNote | 复用onInsert；无能力则隐藏 |
| 消息编辑／删除、候选、分支与上下文路径 | 后续协议与存储 | CH7，未实施 |
| 图片／文件模型输入与预算 | 后续通用合同＋宿主适配 | CH8，未实施 |

框架边界保持：`ChatPanel → RunSession → ChatPort.run → RunEvent`。AutoNote保持薄包装，Web经HTTP、桌面经Aether插件；不在AutoNote复制聊天组件。

## 3. 已实施行为

- 两行紧凑顶部：标题／新建／历史／关闭，模型单独一行；历史支持切换、重命名、删除和加载失败重试。
- 一体输入卡片：上下文标签、原生多行输入、Enter换行、Ctrl/Cmd+Enter发送、IME保护、展开／收起保留草稿与光标、联网／思考／用量／发送／停止能力门控。
- AI回复卡片：思考折叠、工具审批和来源保留；Markdown标题／段落／列表／引用／链接／代码／表格排版；代码和表格内部滚动；DOMPurify安全边界不变。
- 回复内复制、插入、末轮重新生成／失败重试；插入运行时禁用，复制失败显示错误；不添加无后端的编辑／删除／分支／附件按钮。
- 消息区单独滚动；向上阅读时暂停跟随，提供回到底部；无模型、能力加载失败、会话恢复失败、空会话分别处理。
- `scope`仍代表会话归属；聊天`context=null`只表示本轮不带宿主正文。Web／桌面均保留跨用户、错scope、错context、已删除笔记和写作无context拒绝。
