# 27 网络搜索移植设计与开发规划

> 2026-10-13。代码已接入；实际验证与未验证边界见第7节。参考源码：`E:/docs/AI申请/AI安装配置教程/ai/voynote-dev`。
> 范围：Voynote 网络搜索设置、独立网页读取、对话显式预搜索；AutoNote Web/桌面同一界面、相同行为。不是模型自主多轮搜索。
> 2026-10-14增量：Cherry式表单、多Key、压缩、黑名单、模型工具优先与新系统无迁移合同，以[29-网络搜索设置与凭据管理设计.md](29-网络搜索设置与凭据管理设计.md)为准；下文单Key合同是原阶段记录。

## 1. 决策与归属

- Aether 增加独立可选搜索能力：服务商目录、DTO、Rust 请求与解析、SQLite 配置和加密凭据、共享设置组件、Tauri 端口、对话联网开关。
- AutoNote 只负责设置入口、桌面实例创建、笔记上下文和 Web HTTP 适配。
- Cloudflare 后端继续在 AutoNote：D1 按用户隔离、现有 `encryptAiKey/decryptAiKey` 加密、Worker `fetch`。不把 Rust/DPAPI 搬到 Web，也不建通用服务器框架。
- 搜索不能混进模型线路 Store；聊天核心不读取搜索数据库。接入层在用户显式开启后准备搜索上下文，交给既有聊天执行器。
- 不迁移 Voynote 私有数据库、历史配置、旧 IPC 名称；沿用 Aether 的错误、凭据三态、取消、HTTP 地址政策和界面主题。

## 2. 功能合同

### 2.1 搜索与网页读取

两项能力分别选择默认服务商，每个 `(capability, provider)` 独立保存配置。搜索结果数全局 1–50，默认 5；切服务商不清除其他配置或草稿。

- 搜索：智谱、Tavily、SearXNG、Exa、Exa MCP、博查、Querit、Brave、Parallel、Jina、Firecrawl。
- 网页读取：Querit、直接获取、Jina、Firecrawl。
- 默认搜索 Exa MCP、默认读取 Jina，与参考源码一致；匿名服务的可用性/限额由供应商决定，不能承诺永久免费。
- 配置：baseUrl、apiKey（省略保持、空串删除、非空替换）、SearXNG Basic 用户名；配置返回只给掩码及可读状态，明文仅用于后端请求或显式显示。
- 设置检测先提交当前地址及Key草稿，保存失败不得发检测请求；配置修改后旧检测状态失效。HTTP错误或供应商200错误信封均报告失败。新端口/凭据隔离规则见29。
- 网页读取提供真实端口及设置中的 URL 读取操作，显示标题、URL 和纯文本正文；不宣称模型会自动打开搜索结果。

### 2.2 对话

- `RunRequest.webSearch?: boolean`，缺省 false。只允许 chat；写作不隐式联网。
- 开关状态由共享 ChatPanel 保持，在当前面板里持续生效。UI 明确显示正在搜索/失败/无结果，关闭面板和停止均能取消搜索。
- 开启时以本轮实际用户输入查询一次，模型开始前注入编号、标题、URL、摘要；不发送笔记正文、密钥、整个历史给搜索服务商。
- 重新生成使用历史最后一轮的原输入搜索，不能拿空的 regenerate 输入搜索。未开启则不搜索。开关与重试策略在界面可见。
- 搜索失败不得静默降级成无联网回答；不请求模型。已有 accepted 运行则用单一 failed/cancelled 终态结束，不留下 running 记录。
- 零结果正常返回并向用户显示，不伪造来源；模型上下文明确说明未找到结果。失败记录不冒充完成回答。
- 返回网页为不可信数据，使用已有外部上下文边界，不能授予工具权限。编号链接供模型引用；不自动把搜索内容插入笔记。

## 3. 数据和端口

Aether `SearchPort` 为可选 KitPorts 成员，定义：

- `settings(capability)` → `{ capability, defaultProvider, maxResults?, providers }`。
- `save({ capability, provider, baseUrl?, apiKey?, basicAuthUsername? })` → 新设置。
- `setDefault(capability, provider, maxResults?)` → 新设置。
- `reveal(capability, provider)` → 明文密钥；Web 必须验证当前密码（通过宿主端口策略，不弱化现有显示密钥要求）。
- `check(capability, provider, options?)` → `{ count }`。
- `search(query, options?)` → `{ query, provider, hits: [{ title, url, snippet }] }`。
- `fetch(url, options?)` → `{ title, url, content }`。

Tauri 搜索/读取/检测使用 jobId+取消命令，不把 AbortSignal 序列化。配置与执行分离，数据库锁不跨 HTTP。Web 所有请求沿用登录鉴权、owner 限制、Client header、用户配额，所有 SQL 带 user_id。

## 4. 安全与运行限制

- 桌面沿用 Aether `net::check_url/client`，公开地址只允许 HTTPS、本地开发例外。DNS 连接时检查私网地址；不给新搜索功能默默扩大私网 allowlist。
- 自动重定向关闭。直接网页读取允许有限逐跳 GET，每跳重新校验目标、取消与总超时；认证头不转发到另一个 origin。
- Worker 使用 HTTPS、公开目标策略和 `global_fetch_strictly_public`；拒绝 userinfo/私网目标与自动跳转。第三方读取服务收到的目标 URL 也须校验。
- 单次搜索 15 秒，Exa MCP 25 秒，网页读取 20 秒；响应体最多 2 MiB，错误体最多 8 KiB；正文/结果上下文有字符总预算，Unicode 安全截断。请求体/query/URL/密钥均有长度边界。
- 密钥只放供应商要求的认证头，不进入日志、URL、上下文。错误返回脱敏，失败保存保持旧密文。Web 显示密钥验证当前密码。
- 搜索开关提示：用户本轮提问会发送给选定搜索服务商。读取 URL 会发送给选定读取服务商。

## 5. 文件责任与执行顺序

1. **设计先落盘**：本文固定范围、端口、限制与验收。
2. **Aether 核心**：新增 `crates/aether-search`（目录、配置、执行/解析），复用 support；plugin 添加 search feature、实例、命令与权限，chat 接入显式预搜索与取消。
3. **共享 UI**：`packages/ui/src/search`、ports、tauri、ChatPanel/RunSession、两种语言；两张设置卡片沿用已有组件，不复制 Voynote 路由/全局 CSS。
4. **AutoNote**：Worker 搜索配置/路由/执行、D1 追加迁移、HTTP ports；共享设置导航、桌面实例/capability、依赖升级。既有密钥布局与模型加减选择修复必须保留。
5. **验证后收尾**：同协议夹具、真实本地 HTTP/IPC、浏览器和桌面可见界面；记录外部供应商真实联网是否可用。无真实密钥不能将夹具冒充供应商联验。

跨仓库开发允许使用本地临时依赖做验证，但交付不能依赖 `E:/...` 或 `../Aether` 路径。正式依赖需固定可获取的版本/提交或仓库内可复现的包，不留下临时路径与手改 node_modules。
