# 05 协作分工（桌面 agent / Web agent）

> 两个 agent 同时开发时的写入边界。开工前先读本文和 `03-开发任务清单.md` §3。本文只管"谁改哪里"，任务顺序与验收仍以 03 和各详细设计为准。

## 0. 对标参考

AutoNote 以 AutoNote（`<本地仓库目录>`）为对标实现，只是额外增加桌面端。实现任何行为前先读 AutoNote 对应代码，语义不一致时以 AutoNote 为准，有意偏离必须在代码注释和验收记录里写明原因。

| 要实现 | 先读 AutoNote |
| --- | --- |
| 桌面 core 写入/查询/同步载荷（D1、D3、D4、D5） | `src/worker/routes/*.ts`、`src/worker/db/*.ts`、`src/worker/lib/*.ts`、`src/shared/constants.ts` |
| 共享 UI 与状态（S 任务） | `src/client/` 对应组件与 `lib/` |
| 导入导出格式（D3） | `src/worker/routes/transfer.ts`、`src/worker/backup/`、`src/shared/` |
| MCP 工具（D4） | `src/worker/mcp/` |

`AutoNote/web/src/worker` 是迁移副本：2026-10-03 核对 `routes/{notes,folders,tags,sync,settings,files}.ts` 与 AutoNote 无差异，差异仅在 fts 队列、mcp、share、totp、transfer、backup 的少量行，那几处以 AutoNote 原文为基准再看迁移改动。

## 2. 共享根配置

- 集成人：**桌面 agent**（临时，用户可改）。
- 需要新依赖或改根配置：在 §4 写一行"需求 + 原因 + 影响面"，由集成人统一执行 `pnpm install`。**两边不得同时跑 `pnpm install` / 格式化全仓**。
- 已发生的根配置改动（Web 端也受影响，请知悉）：
  - 2026-10-03 `pnpm-workspace.yaml` 新增 `overrides: runed: 0.35.1`。原因：`vaul-svelte@1.0.0-next.7` 带的 `runed@0.23.4` 的 `exports` 只有 `svelte` 条件，Vite 8/Rolldown 的 SSR 构建解析失败。Web 端构建如果用到 vaul/drawer，同样受益。
